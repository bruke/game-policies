# CuteTigerStudio 游戏隐私政策

每款游戏单独使用固定目录。本仓库仅包含公开政策网页。

## 发布
将本目录内容上传到 bruke/game-policies 仓库根目录。
Settings → Pages → Deploy from a branch → main → /(root) → Save。

成语拼游记政策地址（部署成功后）：
https://bruke.github.io/game-policies/chengyu-pinyouji/

一刻时钟政策地址（部署成功后）：
https://bruke.github.io/game-policies/yikeclock/

正式提交前确认网页可匿名访问，发布包的数据处理与政策一致，并在应用内添加政策入口。
未来新增 SDK 或联网功能时需重新核对政策和 Google Play 数据安全声明。
