成语拼游记隐私政策

更新日期：2026年10月3日
开发者：CuteTigerStudio
联系邮箱：boxiaohu@gmail.com

本政策说明 CuteTigerStudio（“我们”）如何处理您使用《成语拼游记》时的信息，适用于本游戏。1.0.0（版本代码 1）为不含广告 SDK 的离线版本；从 1.0.1（版本代码 2）起，Android 版本加入 Google AdMob 激励广告及用户隐私选择功能。封闭测试版本使用 Google 示例广告，但 SDK 的联网与数据处理仍适用本政策。本次更新还加入可选的 Google Analytics for Firebase 使用情况统计，仅在您主动同意后开启。游戏无需账号登录，不含应用内购买。

1. 游戏中的数据处理

答题、词典和游戏存档可在设备本地使用。我们不运营云存档服务器，不上传完整棋盘、收藏列表或完整存档；若您同意使用情况统计，会将关卡编号及关卡开始、结束等行为事件发送给 Google，具体见第 3A 节。游戏不申请通讯录、相机、麦克风或精确定位权限。含广告版本的数据处理见下文；“本地存档”不代表广告 SDK 不联网。

2. 本地存档

游戏在设备的应用存储空间内保存关卡进度、未完成棋盘、收藏、游戏资源、战斗进度及声音和语言设置，以便继续游戏。游戏会使用设备本地时间计算每日奖励和资源恢复。完整存档由游戏在本地保存，不由我们上传至服务器；可选统计会处理部分游玩行为，不用于云存档或恢复游戏进度。

本地存档在您保留应用数据期间保存。您可以通过 Android 系统设置中本应用的“清除存储空间／清除数据”功能删除，卸载应用通常也会删除本地数据。删除后可能无法恢复进度。设备或操作系统自身的备份与恢复由您相应的系统设置和服务提供方管理，我们不运营云存档服务。

3. 激励广告与隐私选择

观看广告是可选功能，可获得提示或体力；不观看仍可继续游戏、使用每日免费提示和自然恢复的体力。首次使用广告前，我们会询问年龄段。年龄段保存在本机，仅将相应的未成年人保护标记传给 Google，不上传出生日期。

广告由 Google AdMob（Google Mobile Ads SDK）提供。SDK 可能收集或分享 IP 地址（用于估计大致位置）、广告及应用交互信息、诊断信息、设备或账号相关标识符（如可用的 Android 广告 ID），用于广告服务、分析及防范欺诈。具体处理受您的隐私选择、设备设置及 SDK 配置影响。SDK 使用 TLS 加密传输。游戏不发送精确位置，不将本地游戏进度传给广告服务。

我们通过 Google 用户消息平台（UMP）检查适用的隐私要求，并在需要时显示同意表单。符合条件后才初始化广告和请求广告。在“设置 → 广告隐私与年龄段”中可修改年龄段；当 Google 要求提供隐私选项入口时，该页面提供“管理广告隐私选择”。在有权撤回同意的地区，您可通过该入口调整选择。您也可在 Android 系统设置中重置或删除广告 ID。

广告服务处理的数据由 Google 按其政策保存，期限取决于数据用途、适用法律和账号设置，我们无法直接删除 Google 持有的所有设备或广告记录。有关处理、保留及隐私权利，请参阅 Google 隐私政策和Google 如何使用合作伙伴应用中的信息。您也可联系我们协助处理隐私请求。

3A. 使用情况统计（可选）

我们使用 Google Analytics for Firebase 分析游戏使用情况、关卡难度及广告奖励链路。首次启动提供独立的同意或拒绝选择，默认不采集；您可在“设置 → 使用情况统计”随时关闭。拒绝或关闭不会影响关卡、奖励及其他游戏功能。广告隐私选择和统计选择分别管理。

同意后，游戏发送关卡编号、词库语言、关卡开始与结束、前台游玩耗时、错误次数、提示次数，以及激励广告请求、展示、结果和奖励到账事件。SDK 还会处理应用实例标识、应用版本、设备与操作系统信息及大致位置信息（如通过 IP 地址推断的国家或地区），用于使用情况分析。游戏不向统计服务发送完整棋盘、答题文字、收藏、姓名、邮箱或出生日期，不设置账号用户 ID，也不向统计服务提供精确定位。统计 SDK 的广告 ID 采集和广告存储、广告用户数据、广告个性化用途被关闭；广告 SDK 的独立处理仍见第 3 节。

我们仅向自报已满 16 周岁且主动同意的用户开启统计；若已在游戏中选择未满 16 周岁的年龄段，则关闭统计。关闭后停止后续采集，并重置本机的 Analytics 数据和应用实例标识；这不等同删除已发送到 Google 的历史数据。数据通过 SDK 加密传输，由 Google 按其政策以及媒体资源的数据保留设置处理和保存。您可通过下述邮箱提出隐私或删除请求。有关 Google 的处理，请参阅 Google 隐私政策和 Firebase 隐私与安全说明。

4. 您主动联系我们时

如果您主动发送电子邮件，我们会收到您的邮箱地址、邮件内容及您自愿提供的附件，仅用于回复咨询、排查问题和处理隐私请求。请勿发送密码或不必要的敏感信息。邮件由邮件服务提供方处理，我们仅在处理事项所需期间保留相关通信；事项结束且无需继续保留时删除，法律要求保留的情况除外。您可通过上述邮箱请求删除相关通信。

5. 外部链接和本政策网页

游戏中的词典来源、许可说明等链接可在浏览器中打开第三方网站。打开后，相应网站按其自身隐私政策处理访问数据。

本政策网页由 GitHub Pages 托管。GitHub 会为安全目的记录访问者的 IP 地址，详情见 GitHub 隐私声明。我们未在本网页添加广告、访问统计脚本、Cookie 或追踪像素。浏览网页时托管服务的处理与离线游戏本身的数据处理不同。

6. 未成年人

本游戏的目标受众为 13 周岁及以上用户。对于自报未满 13 周岁的用户，游戏关闭广告；13–15 周岁的用户使用未达同意年龄的广告保护标记。广告内容等级上限设为 PG。我们不因年龄选择限制离线答题。未成年人通过邮件联系我们时，应避免提供不必要的个人信息，并在适用时取得监护人协助。如监护人认为儿童向我们提供了需要删除的信息，可通过上述邮箱联系我们。

7. 信息安全与共享

本地存档依赖操作系统的应用存储访问控制；请妥善保护设备。对您主动发送的支持邮件，我们限制不必要的访问，不出售或出租这些信息，不将其用于广告营销。仅在提供邮件服务、满足法律要求或处理您授权的请求所必需时处理或披露相应信息。任何存储或通信方式都无法保证绝对安全。

8. 政策更新

如后续版本改变广告或统计配置、加入账号或其他改变数据处理方式的功能，我们会更新本政策及相关商店声明，并在适用时提供通知或取得同意。最新政策发布于此固定网址，并标明更新日期。
